# Reference Oracles

This directory records sealed experimental/reference branches that the reduction program must preserve semantically without merging their implementations into the active restructuring branch.

Current oracle set:

- A2 portable capstone / reconstructed U1-A2.8 chain.
- A3 adaptive compute efficiency.
- Policy-aware orchestrator P1-P5.
- A4 ontology adaptation as a conceptual, explicitly unqualified frontier.

The oracle manifests distinguish **qualified evidence** from **future architectural constraints**.

A3 and P1-P5 are related rather than independent: the P1-P5 branch is downstream of A3 and carries its experimental tree. Reduction must preserve both sets of invariants, but must not double-count inherited artifacts as independent evidence.

The oracle set is intended to become part of dual-layout reconstruction acceptance in R7.

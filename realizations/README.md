# Realizations

This directory represents architecturally meaningful alternative ways to realize the same semantic work.

Validated families include:
- commit: deterministic, WAL, quorum;
- scheduling: FIFO, heuristic, stochastic, adaptive;
- authority and delegation;
- persistence and distributed history;
- networking/transport;
- effects/sagas;
- concurrency/OCC;
- acceleration/NPU;
- adaptive graph composition.

Realization diversity is preserved; this directory is not a deduplication graveyard.

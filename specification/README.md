# Specification

This directory is the future language-neutral semantic surface of UoW.

During R7.1 it is additive only: canonical implementations remain under `src/uow` and the validated research specifications remain under `architecture/spec`.

Validated semantic areas:
- ontology and work contracts;
- authoritative state and identity;
- typed requirements/capabilities and conformance;
- proposal, authorization, transition, and evidence;
- delegation and quorum attestations;
- external-effect boundary;
- wire and canonicalization profiles.

No production import currently depends on this directory.
